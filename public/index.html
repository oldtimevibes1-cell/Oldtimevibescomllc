🔑 API Key Setup Required

To start chatting with Gemini, you need to configure your API key. Follow these steps:

  1. 1 Get your Gemini API key from Google AI Studio
  2. 2 Create a .env file in your project root (if it doesn't exist)
  3. 3 Add your API key to the .env file:
    GEMINI_API_KEY=your_actual_api_key_here
  4. 4 Restart the server to apply the changes

Need help? Check the README.md file for detailed instructions.
